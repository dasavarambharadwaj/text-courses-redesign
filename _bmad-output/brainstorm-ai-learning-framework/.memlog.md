- (direction) Build a lightweight AI skills and folder structure framework for active learning across any domain or interest
- (direction) Must stand on its own as a universal, lightweight learning framework without reference to developer agent frameworks
- (technique) started Job to Be Done
- (idea by coach) Learner hires the folder structure to escape ephemeral chat amnesia: converting transient AI dialogue into permanent knowledge artifacts and self-quizzing rubrics
- (insight by user) Coursera offers rigid one-size-fits-all courses where retaining context and asking deep questions fails; bare AI lacks persistent state and progressive workflow
- (idea by coach) Folder structure as a living curriculum ledger (syllabus.md, mastery-matrix.toml, notes, drills) giving AI instant long-term context across multiple sessions
- (idea by coach) Modular specialized skills for distinct learning modes (Curriculum Architect, Socratic Interrogator, Drillmaster, Knowledge Synthesizer) instead of an all-in-one generic tutor
- (idea by user) Hierarchical structure: Roadmap (macro) -> Course -> Chapter -> Section (micro), modeled like a living textbook
- (idea by user) Dedicated plan/ folder storing roadmap, ingested source materials, and learner profile instructions
- (idea by user) Just-in-time section generation: generate content only when user reaches that section, preventing token bloat and stale material
- (idea by user) Ephemeral dialogue compaction: chat is buffered in a working file, then distilled into permanent section notes upon completion to avoid context loss
- (idea by coach) Verification gate on section completion: a 2-minute Feynman test or drill validates real understanding before distilling notes and marking done
- (idea by coach) Machine-readable manifests (roadmap.toml, course.toml) to track completion status, section sequence, and mastery ledger across agent sessions
- (idea by user) User-controlled completion: user explicitly decides when section/chapter is completed
- (idea by user) Chapter completion milestone: offer optional chapter understanding test and practical assignments based on course domain; user chooses whether to complete
- (idea by user) Upfront course creation: all chapters and sections are fully structured from the start so the complete curriculum is tangible like a textbook
- (idea by coach) Upfront book generation: course creation generates the full book table of contents and lesson.md files upfront, giving the learner a complete structured textbook
- (idea by coach) Chapter capstone: optional chapter-quiz.md and practical-assignment.md tailored to domain (e.g. coding lab, case analysis, financial model), offering elective mastery challenges
- (idea by user) Teaching blueprint file: not user-facing text, but a granular pedagogical checklist specifying every minute concept and learning objective the AI must teach
- (idea by user) Interactive conversational teaching: learner learns through dynamic AI dialogue guided by the blueprint; notes.md becomes the user-facing permanent reference
- (idea by user) Course correction adaptability: upfront full prose is avoided so learners can pivot or refine their curriculum without wasting pre-baked content
- (idea by coach) Naming candidates for teaching blueprint: lesson-plan.md (educator standard), lesson-spec.md (engineering precision), blueprint.md, syllabus.md
- (idea by coach) Checkable concept checklist in the lesson spec: items like '- [ ] Concept X' allowing the AI teacher to track what has been explained and verified in the session
- (decision) Adopted 'lesson-plan.md' as the canonical name for the instructor's granular teaching blueprint
- (idea by user) Proactive topic-by-topic instruction: AI teacher systematically guides the learner through the checklist in lesson-plan.md
- (idea by user) Non-linear navigation: learner can jump to any chapter or section at will, with full persistent tracking across skipped, in-progress, and completed topics
- (idea by coach) Gentle prerequisite advisory on jump-ahead: when user jumps to advanced chapter, AI detects unread prerequisites and offers a 30-second primer before proceeding
- (idea by coach) Universal progress command: instant dashboard showing progress bars, completed vs remaining sections across courses and chapters
- (technique) started Trait Transfer: Grafting skills architecture from proven pedagogical systems
- (idea by user) Course Correct skill (learn-course-correct): reads new inputs only on explicit trigger, maintains a sources ledger of read files, and updates upcoming lesson plans without bloating regular prompts
- (idea by user) Automated Research/Scraper skill (learn-research): triggered by learn-plan to crawl official docs, canonical books, and curriculum standards into scraped sources
- (idea by user) Adversarial Elicitation/Validator skill (learn-challenge): deep Socratic questioning, red-teaming learner mental models, and stress-testing lesson plans for blind spots
- (idea by coach) Sources Ledger (plan/sources/ledger.toml): maintains cryptographic hashes and read history of uploaded files, ensuring zero redundant token reads during normal sessions
- (idea by coach) Three-tier change proposals in learn-course-correct: Minor (bullet added to upcoming lesson-plan), Moderate (new section inserted), Major (roadmap resequenced)
- (idea by coach) Autonomous planning pipeline: learn-plan dispatches learn-research to crawl web docs, drafts roadmap, and runs learn-challenge to audit prerequisites
- (decision) Standardized 4 section lifecycle states: 1. not_started, 2. in_progress, 3. review (post-teaching check/assignment offer), 4. completed
- (idea by user) Master orchestrator / init skill: kicks off onboarding for fresh courses, analyzes current workspace state, and recommends the next best action when learner is unsure
- (idea by user) Distribution & installation: distributed via npx skills <github-url> with automatic skills-lock.json dependency and version locking
- (decision) Adopted clean tc-* namespace skill names: tc-init, tc-plan, tc-research, tc-teach, tc-redirect-course, tc-criticize, tc-test
- (decision) Renamed tc-plan to tc-create: tc-create is the canonical skill for building courses, roadmaps, and lesson plans
- (technique) Deep Adversarial Critique: analyzing all architectural, pedagogical, UX, and technical failure modes
- (insight by coach) Critique 1: Upfront generation token limits: generating 30+ granular lesson-plan.md files in one shot degrades quality; two-tier hierarchical generation needed
- (insight by coach) Critique 2: Active recall vs Lecture Wall: tc-teach must enforce micro-concept turns with mandatory user check questions, preventing passive 'ok next' button mashing
- (insight by coach) Critique 3: Research scraping scope: tc-research must target structured indices (ToCs, docs navigation, awesome lists) rather than raw monolithic book dumps
- (insight by coach) Critique 4: AI-Proof Moat: notes alone don't prove mastery; courses must produce tangible human-crafted artifacts in a projects/ or portfolio/ folder
- (idea by coach) Renaming candidates for tc-criticize: tc-challenge, tc-check, tc-verify, tc-drill, tc-audit
- (decision) Adopted 'tc-verify-course' for curriculum audits and 'tc-test-me' for learner testing and evaluation
- (insight) Finalized TextCourses Framework: tc-* suite (tc-init, tc-create, tc-research, tc-teach, tc-verify-course, tc-test-me, tc-redirect-course), 4-state lifecycle (not_started, in_progress, review, completed), decoupled lesson-plan.md vs notes.md, and ledger-based delta course correction
