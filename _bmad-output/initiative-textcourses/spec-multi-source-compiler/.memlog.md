topic: Multi-Source Deterministic Compiler Specification
updated: 2026-11-02T08:32

- (decision) Discard runtime probabilistic vector RAG in favor of compile-time deterministic source mapping (source-map.toml)
- (decision) Multi-source peer synthesis is the core selling proposition: no primary anchor hierarchy; deduplicate identical topics and merge divergent approaches into dialectic lessons
- (decision) Decouple book academic pedantry from teacher delivery: teacher speaks simply in learner's preferred style under an ironclad zero-unearned-jargon contract
- (constraint) Zero GPU, zero vector database, and zero remote embedding APIs; must run 100% locally on standard library Python and potato-tier hardware
- (constraint) Pure Python PDF extraction (pypdf/pdfplumber); zero mandatory external binary dependencies (pandoc/pdftotext optional)
- (constraint) Conveyor-belt chapter ingestion must cap peak LLM prompt tokens below 25,000 tokens to eliminate context window rot on 500+ page books
- (capability) CAP-1: Verbatim Pure-Python Ingestion | intent: Extract raw prose, code blocks, tables, and headers from PDFs/EPUBs into raw markdown with zero LLM rewriting | success: 100% symbol and code fidelity preserved; scanned image PDFs trigger fail-fast warning
- (capability) CAP-2: Macro Semantic TOC Alignment & Peer Deduplication | intent: Extract TOC ASTs across multiple sources and cluster shared topics into a single deduplicated topological DAG | success: Common topics across multiple books taught exactly once; source-unique topics preserved
- (capability) CAP-3: Conveyor-Belt Chapter Ingestion Pipeline | intent: Process large multi-hundred-page textbooks sequentially chapter-by-chapter with running vocabulary accumulation | success: 500+ page books ingested with prompt tokens bounded under 25k per step without dropped chapters
- (capability) CAP-4: Deterministic Pedagogical Symbol Table (source-map.toml) | intent: Pre-map every concept in lesson-plan.md to exact source files, heading breadcrumbs, and line spans | success: O(1) direct pointer grounding during teach_engine sessions with 0% retrieval miss rate and 0ms search latency
- (capability) CAP-5: Complete Coverage Verification Ledger (coverage-ledger.md) | intent: Generate an audit matrix matching every chapter and section of source books to corresponding course sections | success: Mathematical audit proving 100% textbook coverage without accidental omissions
- (capability) CAP-6: Grounded Sensei Delivery & Vocabulary Contract Enforcement | intent: Deliver lessons in plain English adhering to teacher style, strictly forbidding unintroduced jargon | success: Zero unearned jargon appears in lesson turns; multi-source terminology clashes synthesized into plain-English dialectic explanations
- (decision) Non-goal: Automatic OCR reconstruction of degraded non-searchable image scans (user must supply searchable text/pdf)
- (decision) Non-goal: Arbitrary runtime vector embeddings or vector databases
- (assumption) Modern LLMs at teaching time are sufficiently capable of re-formatting raw extracted text and line wraps into clean markdown code blocks without needing heavy pre-processing
