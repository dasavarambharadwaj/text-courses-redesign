# Curriculum Creation & Triad Consensus

## Description

Implements the curriculum authoring pipeline driven by the Triad Consensus Loop: `tc-create` (Architect), `tc-research` (Scout), and `tc-verify-course` (Auditor). It translates user intent or reference course links into an exhaustive, prerequisite-verified syllabus across the 5 Universal Archetypes, grounded in verified web documentation.

## Outcome

Courses generated by `tc-create` pass pre-flight prerequisite DAG validation and documentation fidelity audits with zero critical findings before any files are written to disk, eliminating prerequisite leaps and hallucinated APIs.

## Requirements

- `FR-4`: Scaffolding courses across 5 Universal Archetypes (Applied Creation, Forensic Dilemma, Axiomatic Primitives, Spiral Immersion, Reverse Engineering).
- `FR-5`: Ingestion of user-supplied curriculum lists or reference course URLs as structural backbones.
- `FR-6`: Multi-tier research scraping with confidence scoring (`high`, `medium`, `low`) and explicit `unverified` fallback tagging.
- `FR-7`: Pre-flight curriculum audit scanning prerequisite DAGs and vocabulary contracts.
- `FR-8`: Triad Consensus Loop logging reconciliation events to `.tc/cache/consensus-trace.jsonl`.

## Done when

1. `/tc-create` prompts for archetype selection and depth preferences, generating `courses/<slug>/overview.md` and chapter structures.
2. User-provided syllabus text or course URLs are parsed into structured chapters.
3. `tc-research` extracts documentation ToCs and API indexes into `.tc/research/<slug>/` with confidence scores.
4. `tc-verify-course` executes `dag.py` graph checks and audits proposed topics against research digests.
5. Files are committed to `courses/` only after reaching consensus with 0 critical findings.

## Boundaries

The curriculum creation skills (`skills/tc-create/`, `skills/tc-research/`, `skills/tc-verify-course/`). Not interactive lesson teaching (Epic 4).
