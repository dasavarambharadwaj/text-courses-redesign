- (decision) Expose ONLY /tc as the single public slash command in the chat UI, collapsing administrative command clutter.
- (decision) Maintain step-by-step interactive checkpoints after research, acquisition, and course creation rather than unattended steamrolling.
- (decision) When gold-standard textbooks cannot be auto-harvested, pause at an acquisition gate asking user to drop files or proceed with open docs.
- (decision) Run multi-agent Triad deliberation silently in background and cap the chat summary to strictly under 40 words to save tokens.
- (decision) Encapsulate machine plumbing files (source-map.toml, coverage-ledger.md, course.toml, memlog.md, session.jsonl) inside courses/<slug>/.tc/.
- (decision) Preserve the standardized 4-Option Action Fork ([1] Next, [2] Test, [3] Re-explain, [4] Custom) at the end of every teaching turn.
- (constraint) Zero regressions across the existing 296 unit and integration test suite.
- (constraint) Zero-BMad invariant across all runtime scripts, tools, and skill definitions.
- (constraint) Potato-proof execution: pure standard Python and local filesystem files with zero GPU or vector database dependencies.
- (capability) CAP-1: Unified Interactive Dispatcher (/tc) routing across onboarding, course creation, and lesson delivery.
- (capability) CAP-2: Step-by-Step Interactive Checkpoint Gates and Missing-Book Acquisition Pause.
- (capability) CAP-3: Zero-Terminal Drop-In Auto-Ingestion of workspace PDFs and EPUBs with scanned image guidance.
- (capability) CAP-4: Two-Tier Clean Workspace Encapsulation moving engine state into courses/<slug>/.tc/.
- (capability) CAP-5: Token-Bounded Background Deliberation Summary constrained to 40 words or fewer.
- (capability) CAP-6: Standardized 4-Option Action Fork preservation with hybrid conversational and numeric responses.
- (event) Spec draft authored and ready for user review.
