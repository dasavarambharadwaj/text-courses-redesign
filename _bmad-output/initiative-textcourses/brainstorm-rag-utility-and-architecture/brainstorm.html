Architecture Shift & Brainstorm Synthesis

The Multi-Source Deterministic Compiler

Replacing runtime probabilistic RAG with compile-time symbol mapping, conveyor-belt digestion, and the Grounded Sensei vocabulary contract.

❌ The Traditional RAG Trap

  • Fuzzy Probabilistic Search: 10–20% of query-time vector searches retrieve the wrong chunks or miss synonyms.
  • Fragmented Context: Arbitrary 500-token chunk boundaries split mathematical proofs and code blocks in half.
  • Broken Pedagogical Sequence: Runtime search pulls Chapter 8 edge cases before Chapter 2 foundations are introduced.
  • Heavy Compute Bloat: Demands vector databases, GPU embedding models, or fragile external cloud APIs.

✅ The Deterministic Compiler Paradigm

  • Deterministic Pointer Retrieval (O(1)): Pre-computed source-map.toml maps every concept directly to verified lines. Zero search latency.
  • Multi-Source Peer Deduplication: Synthesizes 3 books and papers into one unified path. Overlapping topics taught only once.
  • Conveyor-Belt Pipeline: Ingests 600-page textbooks chapter-by-chapter sequentially with zero context window rot.
  • Potato-Proof & Sovereign: 100% standard library Python & local files. Zero GPU, zero vector DB, 0MB RAM overhead.

How the 4-Pass Engine Works

From raw heterogeneous books to pristine interactive lessons.

P0

Pass 0: Verbatim Pure-Python Ingestion

Extract raw text, code blocks, and formulas from PDFs/EPUBs using pypdf / pdfplumber directly into markdown. Strict rule: Zero LLM rewriting during extraction. Pre-flight probe halts on scanned image PDFs.

P1

Pass 1: Macro Semantic TOC Alignment

Extract Table of Contents trees (toc.json) across all uploaded books with zero token bloat. Cluster overlapping topics, preserve unique niche chapters, and assemble a master acyclic Directed Acyclic Graph (DAG).

P2

Pass 2: The Conveyor-Belt Chapter Pipeline

Processes the sources chapter-by-chapter. Feeds Chapter N with a tiny running prerequisite vocabulary ledger. Generates source-map.toml and audits 100% textbook coverage in coverage-ledger.md.

P3

Pass 3: Grounded Sensei Lesson Delivery

During tc-teach, loads the pre-mapped passages directly from source-map.toml. The books establish the factual floor; the Sensei delivers intuitive, plain-English instruction enforcing the Zero-Unearned-Jargon Contract.

✨ The Killer Feature: Dialectic Multi-Source Synthesis

When a learner provides multiple competing books (e.g. Kleppmann's DDIA and Petrov's Database Internals):

# Generated source-map.toml Concept Entry
[[concepts]]
id = "lsm-tree-compaction"
title = "Log-Structured Merge-Trees and Compaction"

]
dialectic = true # Synthesizes write-amplification vs read-amplification trade-offs
Tier Component Architectural Decision
MUST source-map.toml Pre-computed concept-to-exact-source line pointers; O(1) deterministic grounding during teaching.
MUST Verbatim Ingestion Pure Python text/code extraction with zero LLM summarization loss.
MUST Multi-Source Deduplication Identical topics taught only once; divergent approaches merged into dialectic lessons.
MUST Vocabulary Contract Teacher forbidden from using jargon unless taught in prior turns or introduced with everyday intuition first.
WON'T Runtime Vector RAG Eliminated entirely for core curriculum in favor of compile-time deterministic mapping.
WON'T Heavy Vector DBs / GPUs Strict zero ChromaDB, Pinecone, or GPU models. 100% potato-proof sovereign operation.
