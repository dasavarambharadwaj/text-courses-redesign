- (technique) started First Principles Breakdown
- (idea by coach) RAG over generic/popular topics (like Raft, SQL, Rust) adds zero new knowledge to modern LLMs and risks constraining rich synthesis to shallow keyword snippets
- (direction by user) RAG must simultaneously satisfy all 3 jobs: (1) Ingesting new/niche knowledge, (2) Grounding against hallucination, and (3) Strict curriculum fidelity to user-provided source materials
- (idea by coach) Lightweight Semantic Aliases: generate concept synonym maps during index time so potato-proof SQLite BM25 achieves semantic search recall without heavy vector embeddings
- (insight by coach) Current raw BM25 fails Goal 1 (vocabulary mismatch), Goal 2 (no verification gate on hallucinated additions), and Goal 3 (isolated chunks lose chapter dependency spine)
- (idea by user) Verbatim PDF-to-Markdown extraction: extract text and code directly without LLM rewriting to preserve 100% fidelity
- (idea by user) Sequential Source Sweep & Reference Mapping: sweep all sources linearly during course creation to generate a deterministic concept-to-source-location reference file so no topic is skipped
- (decision by user) Adopt Grounded Sensei voice: source materials form the mandatory comprehensive floor (never skip book topics), while teacher is free to enrich with analogies and broader context
- (idea by coach) Deterministic Source Map (source-map.toml): pre-compile every syllabus concept to exact source files, heading paths, and line spans during course creation, eliminating runtime search guesswork
- (idea by coach) Coverage Ledger: generate an audit matrix matching every book section to its mapped course section, mathematically proving 100% topic coverage with zero omitted material
- (insight by coach) Compile-Time Deterministic RAG vs Run-Time Probabilistic RAG: Pre-computing source-map.toml during course creation is vastly superior to runtime vector search for education because it guarantees pedagogical order, zero retrieval misses, and O(1) deterministic grounding
- (idea by coach) Conveyor-Belt Chapter Pipeline: ingest massive 600-page textbooks chapter-by-chapter sequentially with running vocabulary accumulation to completely prevent context window rot while maintaining full-book coverage
- (decision by user) Pure Python PDF extraction: use lightweight pypdf/pdfplumber with zero external binary dependencies, relying on Grounded Sensei LLM to naturally reconstruct code formatting and syntax during lesson delivery
- (technique) started Red Team / Worst-Case Failure Inversion
- (insight by coach) Red Team Vulnerability: Scanned image PDFs yield empty text from pypdf; requires pre-flight text density probe to fail fast and warn user
- (direction by user) Multi-Source Synthesis as Core Selling Proposition: TextCourses' killer feature is synthesizing heterogeneous books, papers, and docs into a single unified learning path with zero primary anchor hierarchy
- (idea by user) Deduplication & Dialectic Synthesis: identical topics are taught only once, while divergent explanations or competing implementations are merged into unified lessons comparing both approaches
- (idea by coach) Two-Phase Multi-Source Compiler: Phase 1 merges TOC trees into a single deduplicated topological DAG; Phase 2 maps multi-book source pointers into source-map.toml with dialectic comparison tags
- (technique) started Radical Alternative / Constraint Shifting
- (decision by user) Tone Decoupling & Vocabulary Contract: Book academic tone must never dictate teaching tone; teacher always speaks simply based on learner level; zero jargon permitted unless explicitly taught in previous lectures
- (idea by coach) Vocabulary Sandbox: feed teacher an explicit whitelist of introduced terms and the 1-2 new terms being taught this turn, forbidding all unintroduced academic jargon
- (decision by coach) Convergence via MoSCoW: Must = Verbatim Ingestion, source-map.toml compile-time mapping, Multi-Source peer deduplication, Conveyor-Belt pipeline, Grounded Sensei with Zero Unearned Jargon; Won't = Heavy vector DBs and runtime probabilistic chunk searching for core syllabus
- (insight by coach) Final Synthesis: The Multi-Source Deterministic Compiler transforms TextCourses from a fragile RAG wrapper into a sovereign pedagogical compiler that reads multiple books verbatim, deduplicates overlapping topics, maps exact line pointers to an acyclic DAG, and instructs with empathetic plain English while enforcing a strict zero-unearned-jargon contract
